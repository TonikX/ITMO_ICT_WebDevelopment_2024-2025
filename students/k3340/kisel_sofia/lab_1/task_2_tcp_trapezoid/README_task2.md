## Принцип работы

1. TCP-сервер:
   - Создаёт TCP-сокет (`socket.AF_INET`, `socket.SOCK_STREAM`);
   - Привязывается к адресу и порту (`127.0.0.1:8080`);
   - Переходит в режим прослушивания и ожидает подключения клиента;
   - После получения данных преобразует их в числа, вычисляет площадь и отправляет результат клиенту.

2. TCP-клиент:
   - Запрашивает у пользователя ввод значений a, b, h;
   - Подключается к серверу и отправляет введённые данные;
   - Получает от сервера результат вычисления и выводит его в консоль.

## Запуск программы
1. Сначала запустить сервер:

python tcp_server.py

2. Затем в другом окне терминала запустить клиента:

python tcp_client.py
