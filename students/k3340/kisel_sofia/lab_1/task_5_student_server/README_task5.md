# Отчёт по заданию 5: CRUD HTTP-сервер (студенты)

## Описание
Реализован **HTTP-сервер** с поддержкой **CRUD-операций** для управления списком студентов.  
Поддерживаемые маршруты:
- `GET /` — форма добавления студента;
- `POST /add` — добавление нового студента;
- `GET /students` — таблица всех студентов.  
Данные хранятся в памяти сервера (список словарей).

## Принцип работы

1. **Парсинг HTTP-запросов**:
   - `parse_request()` разбирает метод, путь, заголовки и тело запроса;
   - `StudentRequest` — класс для хранения данных запроса.

2. **Обработка маршрутов**:
   - `GET /` — HTML-форма для ввода данных студента;
   - `POST /add` — парсит параметры формы (`name=surname=age=`) и добавляет в список;
   - `GET /students` — генерирует HTML-таблицу со списком студентов.

3. **HTTP-ответы**:
   - Формирует корректные заголовки (`Content-Type`, `Content-Length`);
   - Возвращает стилизованные HTML-страницы с CSS.
