# Отчёт по заданию 3: HTTP-сервер

## Описание
Реализован простой HTTP-сервер на сокетах, который обрабатывает GET-запросы и отдаёт статическую HTML-страницу index.html.  
Сервер формирует корректный HTTP-ответ с заголовками и телом ответа.


## Принцип работы

1. HTTP-сервер:
   - Создаёт TCP-сокет (`socket.AF_INET`, `socket.SOCK_STREAM`);
   - Привязывается к адресу и порту (`127.0.0.1:8080`);
   - Ожидает подключения браузера;
   - Читает HTTP-запрос (`conn.recv(1024)`);
   - Загружает содержимое файла index.html;
   - Формирует HTTP-ответ с заголовками:
     - HTTP/1.1 200 OK
     - Content-Type: text/html; charset=utf-8
     - Content-Length
   - Отправляет ответ браузеру.

## Запуск программы
1. Создать файл index.html (пример ниже);
2. Запустить сервер:

python http_server.py
