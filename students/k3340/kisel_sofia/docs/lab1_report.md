# Задание 1: UDP-сервер и клиент

### Описание
В рамках работы реализованы два скрипта: **UDP-сервер** и **UDP-клиент**, которые обмениваются сообщениями по протоколу UDP.  
Клиент отправляет строку `"Hello, server"` серверу, сервер принимает сообщение и отправляет ответ `"Hello, client"`.

### Принцип работы

1. **UDP-сервер**:
   - Создаёт UDP-сокет (`socket.AF_INET`, `socket.SOCK_DGRAM`);
   - Привязывается к указанному адресу и порту (`127.0.0.1:8081`);
   - Ожидает входящее сообщение от клиента;
   - При получении данных выводит сообщение в консоль и отправляет ответ обратно клиенту.

2. **UDP-клиент**:
   - Создаёт UDP-сокет;
   - Отправляет сообщение `"Hello, server"` серверу;
   - Получает ответ `"Hello, client"` и выводит его в консоль.

### Запуск программы
1. Сначала запустить сервер:
   
   python udp_server.py
  
2. Затем в другом окне терминала запустить клиента:
   
   python udp_client.py
  
3. В консоли сервера появится сообщение от клиента, а на клиенте — ответ сервера.


# Задание 2: TCP-сервер и клиент (площадь трапеции)

### Описание
В работе реализован **TCP-сервер** и **TCP-клиент**, взаимодействующие по протоколу TCP.  
Клиент отправляет серверу три значения — основания `a`, `b` и высоту `h` трапеции.  
Сервер вычисляет площадь по формуле  
\[
S = \frac{(a + b) \cdot h}{2}
\]  
и возвращает результат клиенту.


### Принцип работы

1. **TCP-сервер**:
   - Создаёт TCP-сокет (`socket.AF_INET`, `socket.SOCK_STREAM`);
   - Привязывается к адресу и порту (`127.0.0.1:8080`);
   - Переходит в режим прослушивания и ожидает подключения клиента;
   - После получения данных преобразует их в числа, вычисляет площадь и отправляет результат клиенту.

2. **TCP-клиент**:
   - Запрашивает у пользователя ввод значений `a`, `b`, `h`;
   - Подключается к серверу и отправляет введённые данные;
   - Получает от сервера результат вычисления и выводит его в консоль.

### Запуск программы
1. Сначала запустить сервер:
   
   python tcp_server.py
  
2. Затем в другом окне терминала запустить клиента:
   
   python tcp_client.py
  
3. Ввести значения сторон трапеции (например, `a=5`, `b=7`, `h=4`).


# Отчёт по заданию 3: HTTP-сервер

### Описание
Реализован **простой HTTP-сервер** на сокетах, который обрабатывает GET-запросы и отдаёт статическую HTML-страницу `index.html`.  
Сервер формирует корректный HTTP-ответ с заголовками и телом ответа.


### Принцип работы

1. **HTTP-сервер**:
   - Создаёт TCP-сокет (`socket.AF_INET`, `socket.SOCK_STREAM`);
   - Привязывается к адресу и порту (`127.0.0.1:8080`);
   - Ожидает подключения браузера;
   - Читает HTTP-запрос (`conn.recv(1024)`);
   - Загружает содержимое файла `index.html`;
   - Формирует HTTP-ответ с заголовками:
     - `HTTP/1.1 200 OK`
     - `Content-Type: text/html; charset=utf-8`
     - `Content-Length`
   - Отправляет ответ браузеру.

### Запуск программы
1. Создать файл `index.html` (пример ниже);
2. Запустить сервер:
   
   python http_server.py
  
3. Открыть в браузере: `http://127.0.0.1:8080`

### Пример index.html

<html>
<head><title>Test</title></head>
<body><h1>HTTP-сервер работает!</h1></body>
</html>

# Задание 4: Многопользовательский чат

### Описание
Реализован **многопользовательский TCP-чат** с поддержкой нескольких клиентов одновременно.  
Каждый клиент обслуживается в **отдельном потоке** (`threading.Thread`).  
Сервер транслирует сообщения всех клиентов всем остальным участникам чата.

 
### Принцип работы

1. **Сервер**:
   - Хранит словарь подключённых клиентов `{socket: nickname}`;
   - Использует `threading.Lock` для защиты общего словаря;
   - Функция `broadcast()` рассылает сообщения всем клиентам;
   - Для каждого нового клиента создаёт отдельный поток `handle_client()`.

2. **Клиент**:
   - Вводит никнейм и отправляет его серверу;
   - Запускает фоновый поток для приёма сообщений (`receive_messages`);
   - Вводит сообщения в основном потоке и отправляет их серверу.
# Задание 5: CRUD HTTP-сервер (студенты)

### Описание
Реализован **HTTP-сервер** с поддержкой **CRUD-операций** для управления списком студентов.  
Поддерживаемые маршруты:
- `GET /` — форма добавления студента;
- `POST /add` — добавление нового студента;
- `GET /students` — таблица всех студентов.  
Данные хранятся в памяти сервера (список словарей).

 
### Принцип работы

1. **Парсинг HTTP-запросов**:
   - `parse_request()` разбирает метод, путь, заголовки и тело запроса;
   - `StudentRequest` — класс для хранения данных запроса.

2. **Обработка маршрутов**:
   - `GET /` — HTML-форма для ввода данных студента;
   - `POST /add` — парсит параметры формы (`name=surname=age=`) и добавляет в список;
   - `GET /students` — генерирует HTML-таблицу со списком студентов.

3. **HTTP-ответы**:
   - Формирует корректные заголовки (`Content-Type`, `Content-Length`);
   - Возвращает стилизованные HTML-страницы с CSS.
