Задание 1: Создание данных

Описание

Создать 6 новых пользователей-автовладельцев и добавить 5 различных автомобилей. Каждому владельцу присвоить от одной до трёх машин.

from project_first_app.models import CustomUser, Car, Ownership
from datetime import date

# Создание пользователей
owner1 = CustomUser.objects.create_user(username="alexey_smirnov", password="mypassword", passport_number="111222333")
owner2 = CustomUser.objects.create_user(username="tatiana_orlova", password="mypassword", passport_number="222333444")
owner3 = CustomUser.objects.create_user(username="dmitry_belov", password="mypassword", passport_number="333444555")
owner4 = CustomUser.objects.create_user(username="irina_sokolova", password="mypassword", passport_number="444555666")
owner5 = CustomUser.objects.create_user(username="igor_morozov", password="mypassword", passport_number="555666777")
owner6 = CustomUser.objects.create_user(username="marina_efremova", password="mypassword", passport_number="666777888")

# Создание автомобилей
car1 = Car.objects.create(make="Toyota", model="Corolla", color="Black", state_number="ZZZ999")
car2 = Car.objects.create(make="Ford", model="Focus", color="Blue", state_number="YYY888")
car3 = Car.objects.create(make="Volkswagen", model="Golf", color="White", state_number="XXX777")
car4 = Car.objects.create(make="BMW", model="3 Series", color="Red", state_number="WWW666")
car5 = Car.objects.create(make="Audi", model="Q5", color="Green", state_number="VVV555")

# Назначение автомобилей владельцам
Ownership.objects.create(owner=owner1, car=car1, start_date=date(2024, 1, 2))
Ownership.objects.create(owner=owner1, car=car2, start_date=date(2024, 1, 20))
Ownership.objects.create(owner=owner2, car=car3, start_date=date(2024, 2, 5))
Ownership.objects.create(owner=owner3, car=car4, start_date=date(2024, 3, 10))
Ownership.objects.create(owner=owner4, car=car5, start_date=date(2024, 4, 3))
Ownership.objects.create(owner=owner5, car=car2, start_date=date(2024, 5, 7))
Ownership.objects.create(owner=owner6, car=car3, start_date=date(2024, 6, 12))
Ownership.objects.create(owner=owner6, car=car4, start_date=date(2024, 7, 18))

Результат

Владельцы: alexey_smirnov, tatiana_orlova, dmitry_belov, irina_sokolova, igor_morozov, marina_efremova

Машины: Toyota Corolla, Ford Focus, Volkswagen Golf, BMW 3 Series, Audi Q5

Задание 2: Фильтрация данных

Описание

Выполнить выборку данных по определённым критериям.

  1. Все автомобили марки Toyota:
toyota_cars = Car.objects.filter(make="Toyota")
for car in toyota_cars:
    print(car)

Результат:
Toyota Corolla (ZZZ999)

  1. Владельцы, чьи имена содержат "marina":
marina_owners = CustomUser.objects.filter(username__icontains="marina")
for owner in marina_owners:
    print(owner)

Результат:
marina_efremova

  1. Случайный автомобиль и связанный с ним владелец:
import random
random_car = random.choice(Car.objects.all())
owner = random_car.ownership_set.first().owner
print(f"Car: {random_car}, Owner: {owner.username}")

Результат (пример):
Car: Volkswagen Golf, Owner: tatiana_orlova

  1. Все владельцы автомобилей красного цвета:
red_cars = Car.objects.filter(color="Red")
red_car_owners = CustomUser.objects.filter(ownerships__car__in=red_cars).distinct()
for owner in red_car_owners:
    print(owner)

Результат:
dmitry_belov, marina_efremova

  1. Все владельцы, начавшие владение в 2024 году:
owners_from_2024 = CustomUser.objects.filter(ownerships__start_date__year=2024).distinct()
for owner in owners_from_2024:
    print(owner)

Результат:
alexey_smirnov, tatiana_orlova, dmitry_belov, irina_sokolova, igor_morozov, marina_efremova

Задание 3: Анализ данных

Описание

Проанализировать данные с помощью аннотаций и упорядочивания.

  1. Наиболее ранняя дата начала владения:
earliest_ownership_date = Ownership.objects.earliest('start_date').start_date
print(f"Самая ранняя дата начала владения: {earliest_ownership_date}")

Результат:
Самая ранняя дата начала владения: 2024-01-02

  1. Количество автомобилей у каждого владельца:
from django.db.models import Count
owners_with_car_count = CustomUser.objects.annotate(car_count=Count('ownerships__car'))
for owner in owners_with_car_count:
    print(f"{owner.username} имеет {owner.car_count} автомобилей")

Результат:

alexey_smirnov имеет 2 автомобилей
tatiana_orlova имеет 1 автомобилей
dmitry_belov имеет 1 автомобилей
irina_sokolova имеет 1 автомобилей
igor_morozov имеет 1 автомобилей
marina_efremova имеет 2 автомобилей
  1. Подсчет количества автомобилей по каждой марке:
car_make_counts = Car.objects.values('make').annotate(count=Count('make'))
for make_count in car_make_counts:
    print(f"{make_count['make']}: {make_count['count']} шт.")

Результат:

  1. Сортировка владельцев по дате выдачи удостоверения:
sorted_owners_by_license_date = CustomUser.objects.filter(driverlicense__isnull=False).order_by('driverlicense__issue_date')
for owner in sorted_owners_by_license_date:
    license_date = owner.driverlicense_set.first().issue_date
    print(f"{owner.username} - {license_date}")
