# Документация системы управления автобусным парком

## Введение

Данная система предназначена для диспетчера автобусного парка частной транспортной фирмы. Она обеспечивает хранение сведений о водителях, маршрутах и характеристиках автобусов, а также позволяет формировать отчёты и получать необходимую информацию для эффективного управления автопарком.

---

## Модели данных

### Модель `BusType` (Тип автобуса)

**Описание:**

Хранит информацию о типах автобусов и их вместимости.

**Поля:**

- `name` (`CharField`, `max_length=100`): Название типа автобуса.
- `capacity` (`PositiveIntegerField`): Вместимость автобуса данного типа.

**Пример кода:**

```python
from django.db import models

class BusType(models.Model):
    name = models.CharField(max_length=100)
    capacity = models.PositiveIntegerField()

    def __str__(self):
        return f"{self.name} (Capacity: {self.capacity})"
```

---

### Модель `Bus` (Автобус)

**Описание:**

Хранит информацию об отдельных автобусах автопарка.

**Поля:**

- `registration_number` (`CharField`, `max_length=20`, `unique=True`): Номер госрегистрации.
- `bus_type` (`ForeignKey` на `BusType`): Ссылка на тип автобуса.
- `in_service` (`BooleanField`, `default=True`): Статус автобуса (на линии или нет).
- `under_maintenance` (`BooleanField`, `default=False`): В ремонте.

**Пример кода:**

```python
class Bus(models.Model):
    registration_number = models.CharField(max_length=20, unique=True)
    bus_type = models.ForeignKey(BusType, on_delete=models.CASCADE)
    in_service = models.BooleanField(default=True)
    under_maintenance = models.BooleanField(default=False)

    def __str__(self):
        return f"Bus {self.registration_number}"
```

---

### Модель `Driver` (Водитель)

**Описание:**

Хранит информацию о водителях.

**Поля:**

- `passport_data` (`CharField`, `max_length=100`): Паспортные данные.
- `driver_class` (`CharField`, `choices`): Класс водителя (A, B, C).
- `capable_bus_classes` (`ManyToManyField`): Типы автобусов, которыми может управлять.
- `work_experience` (`PositiveIntegerField`): Стаж работы в годах.
- `salary` (`DecimalField`): Зарплата.
- `date_of_birth` (`DateField`): Дата рождения.

**Пример кода:**

```python
class Driver(models.Model):
    passport_data = models.CharField(max_length=100)
    DRIVER_CLASS_CHOICES = [
        ('A', 'Class A'),
        ('B', 'Class B'),
        ('C', 'Class C'),
    ]
    driver_class = models.CharField(max_length=1, choices=DRIVER_CLASS_CHOICES)
    work_experience = models.PositiveIntegerField()
    salary = models.DecimalField(max_digits=10, decimal_places=2)
    date_of_birth = models.DateField()
    capable_bus_classes = models.ManyToManyField(BusType, related_name='qualified_drivers', blank=True)

    def __str__(self):
        return f"Driver {self.passport_data}"
```

---

### Модель `Route` (Маршрут)

**Описание:**

Хранит информацию о маршрутах.

**Поля:**

- `number` (`CharField`, `max_length=20`, `unique=True`): Номер маршрута.
- `start_point` (`CharField`, `max_length=100`): Начальный пункт.
- `end_point` (`CharField`, `max_length=100`): Конечный пункт.
- `operation_start_time` (`TimeField`): Время начала движения.
- `operation_end_time` (`TimeField`): Время окончания.
- `duration` (`DurationField`): Длительность маршрута.

**Пример кода:**

```python
class Route(models.Model):
    number = models.CharField(max_length=20, unique=True)
    start_point = models.CharField(max_length=100)
    end_point = models.CharField(max_length=100)
    operation_start_time = models.TimeField()
    operation_end_time = models.TimeField()
    interval = models.DurationField()
    duration = models.DurationField()

    def __str__(self):
        return f"Route {self.number}: {self.start_point} - {self.end_point}"
```

---

### Модель `WorkShift` (Рабочая смена)

**Описание:**

Хранит информацию о графике работы водителей.

**Поля:**

- `driver` (`ForeignKey` на `Driver`): Водитель.
- `bus` (`ForeignKey` на `Bus`): Автобус.
- `route` (`ForeignKey` на `Route`): Маршрут.
- `date` (`DateField`): Дата смены.
- `shift_start_time` (`TimeField`): Время начала.
- `shift_end_time` (`TimeField`): Время окончания.
- `status` (`CharField`, `choices`): Статус смены.

**Пример кода:**

```python
class WorkShift(models.Model):
    driver = models.ForeignKey(Driver, on_delete=models.CASCADE)
    bus = models.ForeignKey(Bus, on_delete=models.CASCADE)
    route = models.ForeignKey(Route, on_delete=models.CASCADE)
    date = models.DateField()
    shift_start_time = models.TimeField()
    shift_end_time = models.TimeField()
    STATUS_CHOICES = [
        ('Worked', 'Worked'),
        ('Absent', 'Absent'),
        ('Sick', 'Sick'),
        ('Breakdown', 'Breakdown'),
        ('No Driver', 'No Driver'),
        ('No Bus', 'No Bus'),
    ]
    status = models.CharField(max_length=20, choices=STATUS_CHOICES, default='Worked')
    reason = models.TextField(null=True, blank=True)

    def __str__(self):
        return f"Shift on {self.date}: {self.driver} on {self.bus} for {self.route}"
```

## Сериализаторы

**Пример: `WorkShiftSerializer`**

```python
from rest_framework import serializers

class WorkShiftSerializer(serializers.ModelSerializer):
    class Meta:
        model = WorkShift
        fields = '__all__'

    def validate(self, data):
        # Пример валидации перекрывающихся смен
        driver = data.get('driver')
        date = data.get('date')
        overlapping_shifts = WorkShift.objects.filter(
            driver=driver,
            date=date
        )
        if overlapping_shifts.exists():
            raise serializers.ValidationError("Driver already has a shift on this date.")
        return data
```
