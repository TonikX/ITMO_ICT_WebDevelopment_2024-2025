# Lr2 - Django Framework

## Описание

Вторая лабораторная работа посвящена изучению Django Framework. Разработка полнофункционального веб-приложения для управления гонками и участниками.

## Цели работы

- Освоить Django MVC архитектуру
- Работать с моделями данных (ORM)
- Создавать представления (views) и шаблоны (templates)
- Реализовать админ-панель Django
- Работать с формами для обработки данных пользователя

## О приложении Racing App

Веб-приложение для управления автогонками. Позволяет:
- Управлять пользователями (гонщиками) с уровнями опыта
- Создавать команды и управлять участниками
- Регистрировать автомобили владельцев
- Создавать и управлять гонками
- Отслеживать результаты участников

## Основные модели

### User
Расширенная модель пользователя с поддержкой:
- Уровня опыта (Новичок, Любитель, Профессионал)
- Класса гонщика
- Биографии

### Team
- Название команды
- Описание
- Связь с автомобилями

### Car
Реестр автомобилей:
- Связь с владельцем (OneToOne с User)
- Принадлежность к команде (ForeignKey)
- Модель и описание автомобиля
- Год выпуска

### Race
- Название гонки
- Дата и время заезда
- Место проведения
- Статус активности
- Описание
