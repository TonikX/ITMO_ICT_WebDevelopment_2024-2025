# Lr1 - Программирование сокетов

## Описание

Первая лабораторная работа посвящена основам сетевого программирования на Python. Изучаются концепции TCP/UDP сокетов и реализуется собственный HTTP сервер.

## Цели работы

- Освоить основы TCP/UDP протоколов
- Реализовать HTTP сервер с нуля
- Создать различные типы сетевых клиентов
- Понять взаимодействие клиент-сервер модели

## Основные концепции

### TCP Сокеты
- Надёжная доставка данных (connection-oriented)
- Трёхэтапное установление соединения
- Используется для HTTP, FTP и других протоколов

### UDP Сокеты
- Безсвязная доставка (connectionless)
- Быстрая передача без гарантий доставки
- Используется для потокового видео, чатов в реальном времени

### HTTP Протокол
- Request/Response модель
- Методы: GET, POST, PUT, DELETE
- Заголовки и тело сообщения
