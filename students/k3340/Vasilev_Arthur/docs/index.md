# Портфолио Web Development

Добро пожаловать! Здесь собраны все лабораторные работы по курсу Web Development.

## Обзор работ

### [Lr1 - Программирование сокетов](/lr1/)
Основы сетевого программирования на Python. Разработка HTTP сервера и различных сетевых клиентов.

Ключевые темы:
- TCP/UDP сокеты
- HTTP протокол
- Взаимодействие клиент-сервер

---

### [Lr2 - Django Framework](/lr2/)
Веб-приложение для управления гонками и участниками с использованием Django.

Структура:
- Модели USER, Team, Car, Race
- Django ORM
- Admin панель
- Web интерфейс

---

### [Lr3 - Django REST Framework](/lr3/)
REST API с использованием Django REST Framework для двух приложений.

Приложения:
- Warriors App - API для управления воинами с системой навыков
- Printing House - API для управления газетами и типографией

---

### [Lr4 - Full Stack приложение](/lr4/)
Полнофункциональное приложение с Vue.js фронтенд и Django REST бэкэнд.

Компоненты:
- Warriors App - REST API
- Printing House - API для типографии
- Vue.js 3 + TypeScript - современный фронтенд на Vuetify

---

Структура курса:

```
Lr1: Сокеты (Основы)
  ↓
Lr2: Django (Веб-фреймворк)
  ↓
Lr3: REST API (Django REST Framework)
  ↓
Lr4: Full Stack (Vue.js + Django)
```
