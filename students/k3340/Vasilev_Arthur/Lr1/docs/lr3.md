# Лабораторная работа 3: Хакатон API

## Статус: В разработке

Лабораторная работа 3 находится в стадии разработки. Проект будет посвящен созданию REST API для хакатон-платформы.

## Планируемые возможности

- **Регистрация команд и участников**
- **Управление хакатонами**
- **Система оценки проектов**
- **API для интеграции с внешними сервисами**

## Технологии

- **Backend:** Django REST Framework
- **База данных:** PostgreSQL
- **Документация API:** Swagger/OpenAPI
- **Аутентификация:** JWT токены

## Статус проекта

Проект находится в начальной стадии планирования. Структура проекта и базовые модели будут реализованы в ближайшее время.
