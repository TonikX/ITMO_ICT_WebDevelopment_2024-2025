# Лабораторная работа №2 – Табло победителей автогонок

## Цель работы
Реализация простого сайта средствами Django.

**Цель:** овладеть практическими навыками и умениями создания web-сервисов средствами Django 3.

**Оборудование:** компьютерный класс.

**Программное обеспечение:** Python 3.6+, Django 3, PostgreSQL.

## Практическое задание
Реализовать сайт с использованием фреймворка Django 3 и СУБД PostgreSQL, согласно варианту задания.

## Вариант практического задания

### Табло победителей автогонок

Табло должно отображать информацию об участниках автогонок, включая:
- ФИО участника,
- название команды,
- описание автомобиля,
- описание участника,
- опыт и класс участника.

### Функциональные требования

1. **Регистрация пользователей**
   - Позволить новым пользователям регистрироваться на сайте.

2. **Просмотр автогонок и регистрация гонщиков**
   - Пользователи должны иметь возможность просматривать список гонок и регистрироваться на них.
   - Пользователь должен иметь возможность редактировать и удалять свои регистрации.

3. **Написание отзывов и комментариев к автогонкам**
   - Комментатор должен предварительно зарегистрироваться.
   - При добавлении комментария должны сохраняться:
     - Дата заезда,
     - Текст комментария,
     - Тип комментария (вопрос о сотрудничестве, вопрос о гонках, иное),
     - Рейтинг (1-10),
     - Информация о комментаторе.

4. **Административные функции**
   - Администратор должен иметь возможность указывать время заезда и результат через панель Django-admin.

5. **Отображение результатов**
   - В клиентской части должна формироваться таблица всех заездов и результатов конкретной гонки.
