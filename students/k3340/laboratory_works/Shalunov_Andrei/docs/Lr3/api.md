# Документация API автосервиса
## Общее описание
### API предназначен для управления клиентами, сотрудниками, автомобилями, контрактами, а также для выполнения бизнес-логики, связанной с работой автосервиса. Предоставляет возможности CRUD-операций и дополнительные методы для анализа данн

### Эндпоинты
### Клиенты
##### URL: ```/clients/```
##### Методы: ```GET, POST, PUT, DELETE```
##### Описание: Управление информацией о клиентах.

#### Дополнительные действия:
##### ```GET /clients/{id}/yearly_visits/```
##### озвращает информацию о том, как часто клиент посещал автосервис за последний год.

##### Параметры пути:
##### id: Идентификатор клиента.
##### Пример ответа:
```python
{
    "client": "Иван Иванов",
    "visits": 5
}
```
```GET /clients/repeat_clients/```
##### Возвращает список клиентов, которые обращались в автосервис больше одного раза.

##### Пример ответа:
```python
[
    {"full_name": "Иван Иванов", "visits": 3},
    {"full_name": "Петр Петров", "visits": 2}
]
```


### Сотрудники
##### URL: ```/employees/```
##### Методы: ```GET, POST, PUT, DELETE```
##### Описание: Управление информацией о сотрудниках.
#### Дополнительные действия:
```GET /employees/top_mechanic_by_brand/```
##### Возвращает информацию о механике, который чаще всего обслуживает автомобили заданной марки.

#### Query-параметры:
##### brand (обязательный): Марка автомобиля (например, "Toyota").
#### Пример ответа
```
{
    "mechanic_name": "Иван Иванов",
    "job_count": 10
}
```
##### ```GET /employees/{id}/loyal_clients/```
##### Возвращает список постоянных клиентов механика.

#### Параметры пути:
##### id: Идентификатор механика.
#### Пример ответа:
```python
[
    {"client_name": "Иван Иванов"}
]
```

##### ```GET /employees/{id}/delayed_jobs/```
##### Возвращает список работ, не выполненных в срок, и количество дней просрочки для конкретного механика.

#### Параметры пути:
##### id: Идентификатор механика.
#### Пример ответа:
```python
[
    {"client_name": "Петр Петров", "days_late": 3}
]
```
##### ```GET /employees/{id}/monthly_earnings/```
##### Возвращает сумму заработка механика за последний месяц.

#### Параметры пути:
##### id: Идентификатор механика.
#### Пример ответа:
```python
{
    "mechanic_name": "Иван Иванов",
    "total_earnings_last_month": 50000
}
```

```GET /employees/{id}/fines/```
##### Рассчитывает штрафы механика за просроченные работы за последний месяц (5% от стоимости за каждый день).

#### Параметры пути:
##### id: Идентификатор механика.
#### Пример ответа:
```python
[
    {"client_name": "Иван Иванов", "days_late": 3, "fine": 150.0}
]
```

### Автомобили
URL: ```/automobiles/```
Методы: ```GET, POST, PUT, DELETE```
Описание: Управление информацией об автомобилях.

### Контракты
URL: ```/contracts/```
Методы: ```GET, POST, PUT, DELETE```
Описание: Управление контрактами на обслуживание.

### Услуги
URL: ```/services/```
Методы: ```GET, POST, PUT, DELETE```
Описание: Управление списком услуг автосервиса.

### Запчасти
URL: ```/details/```
Методы: ```GET, POST, PUT, DELETE```
Описание: Управление списком запчастей.

### Аутентификация
##### Для всех эндпоинтов требуется аутентификация.
##### Аутентификация осуществляется через ```djoser``` и ```TokenAuthentication```.

### Модели
#### ```Client```: Содержит информацию о клиентах.
#### ```CarWorkshop```: Содержит данные об автосервисах.
#### ```JobPosit```ion: Хранит информацию о должностях сотрудников.
#### ```Employee```: Содержит данные о сотрудниках.
#### ```Model```: Хранит информацию о моделях автомобилей.
#### ```Automobile```: Содержит данные об автомобилях клиентов.
#### ```Contract```: Отслеживает контракты между клиентами и сотрудниками.
#### ```Service```: Содержит список услуг автосервиса.
#### ```Detail```: Хранит данные о запчастях.
#### ```DetailInService```: Связывает запчасти с конкретными услугами.
#### ```DistributionOfWork```: Содержит данные о распределении работ.
