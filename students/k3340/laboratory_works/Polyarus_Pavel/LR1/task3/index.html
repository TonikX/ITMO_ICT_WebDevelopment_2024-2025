О проекте

Это простой HTTP-сервер, реализованный на языке Python с использованием низкоуровневой библиотеки socket. Сервер принимает HTTP-запросы от клиентов и возвращает HTML-страницу, загруженную из файла.

Основные возможности:
  • Обработка HTTP-запросов от браузера
  • Загрузка HTML-контента из файла index.html
  • Формирование корректного HTTP-ответа с заголовками
  • Поддержка множественных подключений
  • Обработка ошибок (404 Not Found)

Технические детали

Сервер использует протокол TCP для надежной передачи данных. При подключении клиента сервер:

  • Принимает входящее соединение
  • Читает HTTP-запрос
  • Загружает содержимое файла index.html
  • Формирует HTTP-ответ со статусом 200 OK
  • Отправляет HTML-страницу клиенту
  • Закрывает соединение

Протокол HTTP

HTTP (HyperText Transfer Protocol) — это протокол прикладного уровня для передачи гипертекстовых документов. Основные компоненты HTTP-ответа:

  • Статус-линия: HTTP/1.1 200 OK
  • Заголовки: Content-Type, Content-Length, Connection
  • Тело ответа: HTML-контент страницы
