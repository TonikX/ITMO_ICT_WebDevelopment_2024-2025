
# API Документация

## Общая информация

Данное API предоставляет доступ к управлению данными о владельцах собак, собаках, выставках, участиях, экспертах и оценках в системе выставок собак.

Все эндпоинты поддерживают методы CRUD, а также имеют дополнительные действия, описанные ниже.

### Аутентификация

Все запросы требуют аутентификации с использованием токена. Токен должен быть передан в заголовке `Authorization` в формате:

```
Authorization: Token <ваш токен>
```

### Фильтрация и сортировка

- **Поиск**: Эндпоинты поддерживают поиск по определенным полям с использованием параметра `search`.
- **Сортировка**: Эндпоинты поддерживают сортировку по определенным полям с использованием параметра `ordering`.

## Эндпоинты

### 1. OwnerViewSet (Владельцы)

**Базовый URL**: `/api/owners/`

#### Методы

- `GET /api/owners/` - Получение списка владельцев.
- `POST /api/owners/` - Создание нового владельца.
- `GET /api/owners/{id}/` - Получение информации о конкретном владельце.
- `PUT /api/owners/{id}/` - Полное обновление информации о владельце.
- `PATCH /api/owners/{id}/` - Частичное обновление информации о владельце.
- `DELETE /api/owners/{id}/` - Удаление владельца.

#### Поиск и сортировка

- **Поиск**: `search` по полям `last_name`, `first_name`, `patronymic`, `contact_info`.
- **Сортировка**: `ordering` по полям `last_name`, `first_name`.

#### Дополнительные действия

##### `GET /api/owners/{id}/rings/` - Информация о рингах владельца

- **Описание**: Получить информацию о рингах, на которых выступают собаки данного владельца.
- **Параметры**:
  - `id` (UUID) - Идентификатор владельца.
- **Пример ответа**:

  ```json
  [
    {
      "show_name": "Осенняя выставка",
      "dog_name": "Бобик",
      "ring_info": "Ринг 1: Лабрадоры, 10:00"
    },
    {
      "show_name": "Зимняя выставка",
      "dog_name": "Рекс",
      "ring_info": "Ринг 2: Немецкие овчарки, 12:00"
    }
  ]
  ```

### 2. DogViewSet (Собаки)

**Базовый URL**: `/api/dogs/`

#### Методы

- `GET /api/dogs/` - Получение списка собак.
- `POST /api/dogs/` - Создание новой собаки.
- `GET /api/dogs/{id}/` - Получение информации о конкретной собаке.
- `PUT /api/dogs/{id}/` - Полное обновление информации о собаке.
- `PATCH /api/dogs/{id}/` - Частичное обновление информации о собаке.
- `DELETE /api/dogs/{id}/` - Удаление собаки.

#### Поиск и сортировка

- **Поиск**: `search` по полям `name`, `breed`, `owner__first_name`, `owner__last_name`, `club_name`.
- **Сортировка**: `ordering` по полям `age`, `name`.

#### Дополнительные действия

##### `POST /api/dogs/{id}/disqualify/` - Дисквалификация собаки

- **Описание**: Отстранить собаку от участия в выставке.
- **Параметры**:
  - `id` (UUID) - Идентификатор собаки.
- **Тело запроса**: не требуется.
- **Пример ответа**:

  ```json
  {
    "status": "Собака Бобик дисквалифицирована"
  }
  ```

##### `GET /api/dogs/by_club/` - Породы клуба

- **Описание**: Получить список пород, представленных заданным клубом.
- **Параметры запроса**:
  - `club_name` (string) - Название клуба (обязательный).
- **Пример запроса**:

  ```
  GET /api/dogs/by_club/?club_name=Клуб любителей собак
  ```

- **Пример ответа**:

  ```json
  {
    "club_name": "Клуб любителей собак",
    "breeds": [
      {"breed": "Лабрадор"},
      {"breed": "Немецкая овчарка"}
    ]
  }
  ```

##### `GET /api/dogs/disqualified_count/` - Количество дисквалифицированных собак

- **Описание**: Получить количество собак, отстраненных от участия в выставке.
- **Параметры**: нет.
- **Пример ответа**:

  ```json
  {
    "disqualified_dogs_count": 5
  }
  ```

##### `GET /api/dogs/participants_by_breed/` - Участники по породам

- **Описание**: Получить количество участников по каждой породе.
- **Параметры**: нет.
- **Пример ответа**:

  ```json
  [
    {"dog__breed": "Лабрадор", "count": 10},
    {"dog__breed": "Немецкая овчарка", "count": 8}
  ]
  ```

### 3. ShowViewSet (Выставки)

**Базовый URL**: `/api/shows/`

#### Методы

- `GET /api/shows/` - Получение списка выставок.
- `POST /api/shows/` - Создание новой выставки.
- `GET /api/shows/{id}/` - Получение информации о конкретной выставке.
- `PUT /api/shows/{id}/` - Полное обновление информации о выставке.
- `PATCH /api/shows/{id}/` - Частичное обновление информации о выставке.
- `DELETE /api/shows/{id}/` - Удаление выставки.

#### Поиск и сортировка

- **Поиск**: `search` по полям `name`, `type`, `location`, `sponsor`.
- **Сортировка**: `ordering` по полям `date`, `name`.

#### Дополнительные действия

##### `POST /api/shows/{id}/add_expert/` - Добавить эксперта к выставке

- **Описание**: Добавить эксперта к выставке.
- **Параметры**:
  - `id` (UUID) - Идентификатор выставки.
- **Тело запроса**:

  ```json
  {
    "expert_id": "UUID эксперта"
  }
  ```

- **Пример ответа**:

  ```json
  {
    "status": "Эксперт Петр Петров добавлен к выставке Осенняя выставка"
  }
  ```

##### `POST /api/shows/{id}/remove_expert/` - Удалить эксперта с выставки

- **Описание**: Снять эксперта с судейства на выставке.
- **Параметры**:
  - `id` (UUID) - Идентификатор выставки.
- **Тело запроса**:

  ```json
  {
    "expert_id": "UUID эксперта"
  }
  ```

- **Пример ответа**:

  ```json
  {
    "status": "Эксперт Петр Петров удален с выставки Осенняя выставка"
  }
  ```

##### `GET /api/shows/{id}/results/` - Результаты выставки

- **Описание**: Получить отчет о результатах заданной выставки.
- **Параметры**:
  - `id` (UUID) - Идентификатор выставки.
- **Пример ответа**:

  ```json
  {
    "total_participants": 50,
    "breeds": [
      {"dog__breed": "Лабрадор"},
      {"dog__breed": "Немецкая овчарка"}
    ],
    "participants_by_breed": [
      {"dog__breed": "Лабрадор", "count": 30},
      {"dog__breed": "Немецкая овчарка", "count": 20}
    ],
    "medals_by_breed": [
      {"dog__breed": "Лабрадор", "medal": "Золото", "count": 5},
      {"dog__breed": "Немецкая овчарка", "medal": "Серебро", "count": 3}
    ]
  }
  ```

- **Пример ответа**:


## Примеры использования фильтров

### Поиск

- **Пример**: Найти всех владельцев с фамилией "Иванов".

  ```
  GET /api/owners/?search=Иванов
  ```

- **Пример**: Найти всех собак породы "Лабрадор".

  ```
  GET /api/dogs/?search=Лабрадор
  ```

### Сортировка

- **Пример**: Получить список собак, отсортированных по возрасту по убыванию.

  ```
  GET /api/dogs/?ordering=-age
  ```

- **Пример**: Получить список выставок, отсортированных по дате.

  ```
  GET /api/shows/?ordering=date
  ```
