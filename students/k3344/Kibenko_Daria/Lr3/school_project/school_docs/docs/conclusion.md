# Заключение

В ходе работы была успешно разработана модель данных для школьной системы, охватывающая такие аспекты, как предметы, классы, ученики, учителя, оценки и расписание. Создание и наполнение базы данных начальными данными прошло без ошибок. Также был разработан API для взаимодействия с данными через Django REST Framework, что позволяет гибко управлять школьной информацией.
