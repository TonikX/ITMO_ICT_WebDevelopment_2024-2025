# Запуск и требования

## Требования

- Python 3 (проверка: `python3 --version`).
- Терминал Linux/Ubuntu (WSL) или другой среды с Python 3.
- Браузер для заданий 3 и 5.
- Свободные локальные порты `12345`, `12346`, `8080`, `12347`, `8081`.

Все скрипты используют стандартную библиотеку: устанавливать сторонние Python-пакеты для запуска заданий не требуется.

## Структура проекта

```text
laboratory_work_1/
├── task_1/              # UDP-клиент и сервер
├── task_2/              # TCP и вычисление площади
├── task_3/              # HTTP-сервер и index.html
├── task_4/              # Многопользовательский TCP-чат
├── task_5/              # Журнал оценок GET/POST
├── screenshots/         # Скриншоты выполнения
├── docs/                # Страницы документации
├── mkdocs.yml           # Конфигурация сайта
├── requirements-docs.txt
└── README.md
```

## Запуск приложений

=== "UDP и TCP (1–2)"

    Откройте **два терминала**. В первом запустите сервер, затем во втором — клиент.

    ```bash
    cd laboratory_work_1/task_1
    python3 server.py
    ```

    ```bash
    cd laboratory_work_1/task_1
    python3 client.py
    ```

    Для второй задачи замените `task_1` на `task_2`, а имена файлов — на `tcp_server.py` и `tcp_client.py`.

=== "HTTP (3 и 5)"

    Из соответствующего каталога запустите сервер:

    ```bash
    cd laboratory_work_1/task_3
    python3 http_server.py
    ```

    Откройте `http://127.0.0.1:8080/` в браузере. Для пятой задачи запустите `task_5/grades_server.py` и откройте `http://127.0.0.1:8081/`.

=== "Чат (4)"

    Нужны **три терминала**: сервер и два клиента.

    ```bash
    cd laboratory_work_1/task_4
    python3 chat_server.py
    ```

    В остальных двух терминалах из той же папки:

    ```bash
    python3 chat_client.py
    ```

    Укажите разные имена, затем отправьте сообщения. Для выхода используйте `/exit`.

!!! warning "Рабочий каталог имеет значение"
    Третье задание открывает файл `index.html` по относительному пути. Поэтому команду `python3 http_server.py` нужно запускать именно из `task_3`, иначе возникнет `FileNotFoundError`.

## Локальный просмотр MkDocs

Из каталога `laboratory_work_1` выполните:

```bash
python3 -m pip install -r requirements-docs.txt
python3 -m mkdocs serve
```

После запуска откройте адрес, который напечатает MkDocs (обычно `http://127.0.0.1:8000/`). Для сборки статического сайта:

```bash
python3 -m mkdocs build --strict
```

Сгенерированные HTML-файлы появятся в каталоге `site/`. Этот каталог — результат сборки, его не обязательно добавлять в Git.

## Частые проблемы

| Симптом | Причина | Что проверить |
|---|---|---|
| `ConnectionRefusedError` | Клиент стартовал до сервера | Запустить сервер первым; проверить порт |
| `Address already in use` | Порт занят другим процессом | Остановить прежний экземпляр сервера |
| Браузер не открывает страницу | Сервер остановлен или выбран другой порт | Адрес `127.0.0.1:8080` либо `:8081` |
| `FileNotFoundError: index.html` | Неверный рабочий каталог | Перейти в `task_3` перед запуском |
| Не отображаются новые оценки после перезапуска | Данные хранятся в оперативной памяти | Добавить оценки заново; постоянное хранение не реализовано |

!!! tip "Остановка"
    HTTP-серверы и чат работают до остановки процесса. В терминале обычно достаточно сочетания ++ctrl+c++.
