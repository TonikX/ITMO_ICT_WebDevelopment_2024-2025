# Вывод

В ходе выполнения лабораторной работы был разработан веб-сайт «Табло авиаперелетов» с использованием фреймворка Django.

Были решены следующие задачи:
1. Спроектирована и реализована модель данных (Авиакомпании, Аэропорты, Рейсы).
2. Реализован паттерн MVT.
3. Настроена пагинация и фильтрация данных.
4. Реализовано разграничение прав доступа (администратор и обычный пользователь) на уровне клиентского интерфейса.
5. Интерфейс стилизован с помощью Bootstrap 5 и кастомного CSS.

В результате работы были получены практические навыки разработки веб-приложений на Python/Django.
