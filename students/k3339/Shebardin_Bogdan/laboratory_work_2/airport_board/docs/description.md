# Описание проекта

Для реализации проекта была выбрана архитектура **MVT (Model-View-Template)**, которая является вариацией классического паттерна MVC.

**Используемые технологии:**
*   **Python 3.12** — язык программирования.
*   **Django 5** — веб-фреймворк.
*   **SQLite** — база данных (для локальной разработки, структура совместима с PostgreSQL).
*   **Bootstrap 5** — CSS-фреймворк для стилизации.
*   **Кастомный CSS** — для создания эффекта «темного аэропортового табло» (Glassmorphism, неоновые акценты).

**Структура проекта:**
*   `config/` — настройки проекта (`settings.py`, `urls.py`).
*   `flights/` — основное приложение (модели, представления, шаблоны).
