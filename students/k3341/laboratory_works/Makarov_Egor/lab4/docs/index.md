# Hackathon API — Лабораторная работа №3

**Бонусный вариант от Давида: система проведения хакатонов**

В проекте реализованы:
- Django 3 + Django REST Framework
- Djoser (регистрация/авторизация по токенам)
- PostgreSQL (через переменные окружения)
- Роли: ADMIN / CURATOR / JURY / CAPTAIN
- CRUD + вложенные выдачи (1-to-many и many-to-many)
- 4 аналитических (агрегационных) запроса

Смотрите разделы слева: установка, роли, эндпоинты, практика по ORM-запросам.
