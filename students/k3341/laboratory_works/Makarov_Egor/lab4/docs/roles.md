# Роли и права доступа

## Роли
- **ADMIN** (главный администратор)
  - создаёт задачи, назначает кураторов
  - смотрит всё
  - *не создаёт команды, не редактирует решения, не ставит оценки* (в логике проекта это запрещено)
- **CURATOR** (куратор задач)
  - назначается на одну задачу (OneToOne)
  - добавляет ссылки и файлы к задаче
  - видит решения по своей задаче
- **JURY** (жюри)
  - видит решения
  - ставит оценки и комментарии
- **CAPTAIN** (капитан)
  - регистрируется
  - создаёт 1 команду (OneToOne)
  - выбирает 1 задачу
  - заполняет состав команды
  - отправляет решение

## Как выставить роль
В админке Django:
`UserProfile.role` → ADMIN/JURY/CURATOR/CAPTAIN

По умолчанию после регистрации роль = CAPTAIN.
