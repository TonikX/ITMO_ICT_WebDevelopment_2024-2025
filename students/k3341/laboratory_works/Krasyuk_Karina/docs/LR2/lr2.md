## Лабораторная работа 2: Табло автогонок

### Задание

Реализовать сайт используя фреймворк Django 3 и СУБД PostgreSQL *, в соответствии с вариантом задания лабораторной
работы.
Вариант: 6 - Табло автогонок.

Должны быть реализованы следующие модели:

- Гонщик
- Регистрация гонщика
- Гонка
- Отзыв

Необходимо реализовать следующий функционал:

- Регистрация новых пользователей.
- Просмотр автогонок и регистрация гонщиков. Редактирование и удаление регистраций.
- Написание отзывов к гонкам. При добавлении комментариев, должны
  сохраняться даты заезда, текст комментария, рейтинг (1-10),
  информация о комментаторе, тип комментария.
- Администратор должен иметь возможность указать время заезда и результат средствами Django-adminю
- В клиентской части должна формироваться таблица всех заездов и результатов конкретной гонки.


# Запуск

## Первый запуск

```zsh
pip install -r requirements.txt
docker run --name pg-container -e POSTGRES_PASSWORD=notsecred -d -p 5432:5432 postgres
python manage.py runserver localhost:8000
```

## Дальнейшие запуски

```zsh
docker start postgres-container
python manage.py runserver localhost:8000
```
