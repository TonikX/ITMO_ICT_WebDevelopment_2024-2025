# Навигация по веб-приложению

Для навигации по веб-приложению были прописаны все абсолютные пути в файле urls.py

## Навигация

Все страницы дополнительно имеют шапку, которая имеет переходы на следующие страницы при данных условиях

- *Get back* - переход на предыдущую в иерархии страницу; всегда
- /conference
- /conference/create - при наличии учётной записи
- /register - при отсутствии учётной записи
- /login - при отсутствии учётной записи
- /logout - при наличии учётной записи

Пути страниц, описание и условия доступа

- / - корень приложения, автоматический редирект на /conference; всегда
- /register - страница регистрации пользователя; успешная регистрация переводит на /login; всегда
- /login - страница аутентификации пользователя; успешная аутентификация переводит на /; всегда
- /logout - страница выхода из учётной записи пользователя; переводит на /; всегда
- /conference - содержит список всех конференций с пагинацией; всегда; каждая конфереция имеет переходы на
    - /conference/{conf_id} - всегда
    - /conference/{conf_id}/update - если админ или создатель конференции
    - /conference/{conf_id}/delete - если админ или создатель конференции
- /conference/create - форма создание конференции; при наличии учётной записи
- /conference/{conf_id} - страница конференции c деатальной информацией, списком выступающих и отзывов; всегда; имеет переходы
    - /conference/{conf_id}/auditor - если есть учётная запись и ещё не слушатель
    - /conference/{conf_id}/speaker/create - если есть учётная запись и ещё не выступающий
    - /conference/{conf_id}/speaker/update - если выступление зарегистрировано на вашую учётную запись
    - /conference/{conf_id}/speaker/delete - если выступление зарегистрировано на вашую учётную запись
    - /conference/{conf_id}/review/create - если есть учётная запись
    - /conference/{conf_id}/review/{review_id} - всегда
- /conference/{conf_id}/update - страница изменения данных о конференции; если конференция зарегистрирована на вашу учётную запись или админ
- /conference/{conf_id}/delete - страница удаления конференции; если конференция зарегистрирована на вашу учётную запись или админ
- /conference/{conf_id}/speaker/create - страница создания выступления; если есть учётная запись
- /conference/{conf_id}/speaker/update - страница изменения данных о выступлении; если есть учётная запись
- /conference/{conf_id}/speaker/delete - страница удаления выступления; если есть учётная запись
- /conference/{conf_id}/auditor - регистрация в качестве слушателя; если есть учётная запись
- /conference/{conf_id}/review/create - страница создания отзыва; если есть учётная запись
- /conference/{conf_id}/review/{review_id} - страница с деталями отзыва и комментарии; всегда; имеет переходы
    - /conference/{conf_id}/review/{review_id}/update - если создатель отзыва или админ
    - /conference/{conf_id}/review/{review_id}/delete - если создатель отзыва или админ
    - /conference/{conf_id}/review/{review_id}/comment/create - если есть учётная запись
- /conference/{conf_id}/review/{review_id}/update - страница для изменения отзыва; если создатель отзыва или админ
- /conference/{conf_id}/review/{review_id}/delete - страница для удаления отзыва; если создатель отзыва или админ
- /conference/{conf_id}/review/{review_id}/comment/create - создание нового комментария к отзыву; если есть учётная запись
