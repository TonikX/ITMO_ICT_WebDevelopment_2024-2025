# Представления

Здесь описаны все контроллеры, используемые для взаимодействия с веб-приложением

## User view

Контроллеры отвечающие за взаимодействие с пользователем. Состоит из следующих представлений:

- def index(request) - контроллер, отвечающий за /; всегда редиректит на /conference
- class RegisterUserView(View) - контроллер, отвечающий за /register;
    - get: страница с формой регистрации
    - post: проверка отправленной формы и регистрация пользователя, если форма невалидна - возвращает страницу с формой
- class LoginUserView(View) - контроллер, отвечающий за /login;
    - get: страница с формой логина
    - post: проверка отправленной формы и авторизация пользователя, если форма невалидна - возвращает страницу с формой
- class UserLogout(LogoutView) - контроллер, отвечающий за деаутентификацию пользователя
    - get: деаутентифицирует пользователя и перенаправляет на /

## Conference View

Контроллер отвечающие за взаимодействие с моделью конференции. Состоит из следующих представлений:

- class ConferenceList(ListView) - контроллер, отвечающий за /conference; список содержит пагинацию
    - get: страница со списком всех конференция
- class ConferenceDetail(DetailView) - контроллер, отвечающий за /conference/{conf_id}
    - get: страница с деталями конференции
- class ConferenceCreate(CreateView) - контроллер, отвечающий за /conference/create
    - get: страница с формой создания новой конференции
    - post: проверка отправленной формы и создание новой конференции, если форма невалидна - возвращает страницу с формой
- class ConferenceUpdate(UpdateView) - контроллер, отвечающий за /conference/{conf_id}/update
    - get: страница с формой изменения конференции
    - post: проверка отправленной формы и изменение конференции, если форма невалидна - возвращает страницу с формой 
- class ConferenceDelete(DeleteView) - контроллер, отвечающий за /conference/{conf_id}/delete
    - get: страницой с формой подтверждения удаления
    - post: проверка подтверждения и удаление конференции из базы данных, если форма невалидна - возвращает страницу с формой
- class ConferenceAuditor(View) - контроллер, отвечающий за /conference/{conf_id}/auditor
    - post - создание новой записи в ConferenceAuditor с данным пользователем с данной конференцией

    - post: проверка формы и создание нового выступления, если форма невалидна - возвращает страницу с формой
- class SpeakerUpdate(UpdateView) - контроллер, отвечающий за /conference/{conf_id}/speaker/update
    - get: страница с формой изменения выступления
    - post: проверка формы и изменение выступления, если форма невалидна - возвращает страницу с формой
- class SpeakerDelete(DeleteView) - контроллер, отвечающий за /conference/{conf_id}/speaker/delete
    - get: страница с формой подтверждения удаления
    - post: проверка подтверждения и удаление выступления, если форма невалидна - возвращает страницу с формой

## Review view

Контроллер отвечающие за взаимодействие с моделью отзыва. Состоит из следующих представлений:

- class ReviewDetail(DetailView) - контроллер, отвечающий за /conference/{conf_id}/review/{review_id}
    - get: страница с информацией об отзыве
- class ReviewCreate(View) - контроллер, отвечающий за /conference/{conf_id}/review/create
    - get: страница с формой создания нового отзыва
    - post: проверка формы и создание нового отзыва, если форма невалидна - возвращает страницу с формой
- class ReviewUpdate(UpdateView) - контроллер, отвечающий за /conference/{conf_id}/review/{review_id}/update
    - get: страница с формой изменения отзыва
    - post: проверка формы и изменение отзыва, если форма невалидна - возвращает страницу с формой
- class ReviewDelete(DeleteView) - контроллер, отвечающий за /conference/{conf_id}/review/{review_id}/delete
    - get: страница с подтверждением удаления отзыва
    - post: проверка подтверждения и удаление отзыва из базы данных, если подтверждение невалидно - страница с подтверждением

## Commentary view

Контроллер отвечающие за взаимодействие с моделью комментария. Состоит из следующих представлений:

- class CommentCreate(View) - контроллер отвечающий за /conference/{conf_id}/review/{review_id}/comment/create
    - post: проверка формы комментария и создание нового комментария в базе данных, потом возвращает на страницу с отзывом
