# Авторизация

## Регистрация

Для регистрации нужно обратиться по ручке auth/users/ POST-запросом. Тело запроса должно содержать поля:

* email
* username
* password

Пароль не должен быть простым

## Аутентификация

Для аутентификации нужно обратиться по ручке auth/token/login/ POST-запросом. Тело запроса должно содержать поля:

* username
* password

Ответ сервера содержит JSON с полем auth_token. Для доступа к API приложения нужно добавить заголовок Authorization со значением "Token {auth_token}" в запрос. Без наличия корректного токена не позволяет обращаться к основному функционалу API приложения.
