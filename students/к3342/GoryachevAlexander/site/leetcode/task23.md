# 29. Divide Two Integers
1.	Преобразование знаков: Начнем с обработки знаков чисел. Если делимое или делитель отрицательные, это повлияет на знак результата. Мы можем сначала привести оба числа к положительным, работать с ними, а потом вернуть правильный знак для результата.
2.	Деление с использованием вычитаний: Вместо того чтобы делить числа через операторы, будем вычитать делитель из делимого до тех пор, пока это возможно. Это примитивный способ деления.
3.	Оптимизация с использованием сдвигов: Чтобы ускорить процесс вычитания, можно использовать двоичные сдвиги. Мы будем удваивать делитель, сдвигая его влево, и таким образом, будем вычитать большие куски, что значительно ускоряет процесс.
Решение:
```python
def divide(dividend, divisor):
    # Определение границ
    INT_MAX = 2**31 - 1
    INT_MIN = -2**31
    
    # Если делитель равен 0, возвращаем ошибку (в реальной задаче надо было бы бросать исключение)
    if divisor == 0:
        raise ValueError("Cannot divide by zero")
    
    # Определяем знак результата
    negative = (dividend < 0) != (divisor < 0)
    
    # Приводим оба числа к положительным
    dividend, divisor = abs(dividend), abs(divisor)
    
    # Результат
    quotient = 0
    # Пока делимое больше или равно делителю
    while dividend >= divisor:
        temp, multiple = divisor, 1
        # Увеличиваем делитель с помощью сдвигов (умножаем на 2) и считаем количество
        while dividend >= (temp << 1):
            temp <<= 1
            multiple <<= 1
        
        # Вычитаем удлинённый делитель и увеличиваем результат
        dividend -= temp
        quotient += multiple
    
    # Применяем знак результата
    if negative:
        quotient = -quotient
    
    # Обрабатываем границы 32-битных целых чисел
    if quotient < INT_MIN:
        return INT_MIN
    if quotient > INT_MAX:
        return INT_MAX
    
    return quotient
```
