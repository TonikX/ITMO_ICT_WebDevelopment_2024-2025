# 17. Letter Combinations of a Phone Number
1.	Нам дается строка с цифрами от 2 до 9, каждая цифра может быть сопоставлена с несколькими буквами (по аналогии с клавишами на телефоне).
2.	Для каждой цифры будем искать все соответствующие буквы, и затем будем перебирать все возможные комбинации этих букв.
3.	Мы можем использовать рекурсию или перебор с помощью очереди (итерации).

Решение:
```python
def letterCombinations(digits):
    if not digits:
        return []

    # Маппинг цифр на соответствующие буквы
    phone_map = {
        '2': ['a', 'b', 'c'],
        '3': ['d', 'e', 'f'],
        '4': ['g', 'h', 'i'],
        '5': ['j', 'k', 'l'],
        '6': ['m', 'n', 'o'],
        '7': ['p', 'q', 'r', 's'],
        '8': ['t', 'u', 'v'],
        '9': ['w', 'x', 'y', 'z']
    }

    # Рекурсивная функция для нахождения всех комбинаций
    def backtrack(index, path):
        # Если достигнут конец строки, добавляем путь в результат
        if index == len(digits):
            combinations.append("".join(path))
            return
        
        # Получаем буквы, соответствующие текущей цифре
        letters = phone_map[digits[index]]
        
        # Перебираем все буквы для текущей цифры
        for letter in letters:
            path.append(letter)  # Добавляем букву в текущий путь
            backtrack(index + 1, path)  # Рекурсивный вызов для следующей цифры
            path.pop()  # Убираем букву из пути (для возвращения к предыдущему состоянию)

    combinations = []
    backtrack(0, [])  # Начинаем с индекса 0 и пустого пути
    return combinations
```
