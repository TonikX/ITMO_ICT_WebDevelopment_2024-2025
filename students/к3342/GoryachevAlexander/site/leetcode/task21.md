# 27. Remove Element
1.	Инициализация указателя:
•	Используем указатель i, который будет указывать на текущую позицию для записи элементов, не равных val.
2.	Итерация по массиву:
•	Пройдем по каждому элементу массива с помощью другого указателя j.
•	Если элемент nums[j] не равен val, запишем его в текущую позицию i и увеличим указатель i.
3.	Результат:
•	После завершения итерации указатель i будет содержать количество элементов, которые не равны val, и массив будет изменен так, что первые i элементов содержат все уникальные значения.


Решение:
```python
# Определение структуры узла связанного списка
def removeElement(nums, val):
    i = 0  # Указатель для записи элементов, не равных val

    for j in range(len(nums)):
        if nums[j] != val:
            nums[i] = nums[j]
            i += 1

    return i  # Возвращаем количество элементов, не равных val
```
