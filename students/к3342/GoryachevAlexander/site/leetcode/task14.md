# 18. 4Sum
1.	Сортировка массива: Это позволит нам избегать дублирующих квадруплетов, а также эффективно использовать два указателя.
2.	Использование двух указателей: Для каждой пары чисел мы будем искать еще два числа, сумма которых вместе с текущей парой даст нужную сумму.
3.	Пропуск одинаковых элементов: Для того чтобы избежать дублирования, будем пропускать одинаковые элементы на каждом шаге для каждого из указателей.

Решение:
```python
def fourSum(nums, target):
    # Сортируем массив для удобства поиска
    nums.sort()
    result = []
    
    # Перебираем первый элемент
    for i in range(len(nums) - 3):
        # Пропускаем дубли для первого элемента
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        
        # Перебираем второй элемент
        for j in range(i + 1, len(nums) - 2):
            # Пропускаем дубли для второго элемента
            if j > i + 1 and nums[j] == nums[j - 1]:
                continue
            
            # Используем два указателя для поиска оставшихся двух чисел
            left, right = j + 1, len(nums) - 1
            while left < right:
                total = nums[i] + nums[j] + nums[left] + nums[right]
                
                if total == target:
                    # Нашли квадруплет, добавляем его в результат
                    result.append([nums[i], nums[j], nums[left], nums[right]])
                    
                    # Пропускаем дубли для третьего и четвертого элементов
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1
                    
                    # Двигаем указатели
                    left += 1
                    right -= 1
                elif total < target:
                    # Если сумма меньше целевой, сдвигаем левый указатель вправо
                    left += 1
                else:
                    # Если сумма больше целевой, сдвигаем правый указатель влево
                    right -= 1
    
    return result
```
