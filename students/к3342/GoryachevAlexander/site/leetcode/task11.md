# 14. Longest common prefix
1.	Начнем с самой первой строки как предполагаемой общей приставки.
2.	Для каждой следующей строки будем проверять, насколько она совпадает с текущей общей приставкой. Для этого будем сокращать общую приставку до тех пор, пока она будет оставаться префиксом текущей строки.
3.	Если на каком-то этапе общая приставка становится пустой, значит общая приставка для всех строк отсутствует.
4.	Если мы прошли все строки, то возвращаем общую приставку.

Решение:
```python
def longestCommonPrefix(strs):
    if not strs:
        return ""

    # Изначально предполагаем, что префикс - это первая строка
    prefix = strs[0]
    
    for string in strs[1:]:
        # Сравниваем текущий префикс с каждой строкой
        while not string.startswith(prefix):
            # Укорачиваем префикс, пока не найдем общую часть
            prefix = prefix[:-1]
            if not prefix:
                return ""  # Если префикс стал пустым, значит нет общей приставки
    
    return prefix
```
