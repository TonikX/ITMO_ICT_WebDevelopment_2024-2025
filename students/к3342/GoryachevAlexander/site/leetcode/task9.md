# 11. Container With Most Water
Алгоритм решения задачи:
    1. Инициализируем два указателя:
	•	left — на первом элементе массива (индекс 0).
	•	right — на последнем элементе массива (индекс n-1).
	2.	В каждой итерации вычисляем возможный объём воды, который можно вместить между линиями с индексами left и right:
	•	Объём воды вычисляется как: min(height[left], height[right]) * (right - left), где min(height[left], height[right]) — это высота, которая ограничивает уровень воды (меньшая из двух линий), а (right - left) — это ширина контейнера.
	3.	Сохраняем максимальный объём воды, найденный за время работы алгоритма.
	4.	Сдвигаем указатель:
	•	Если height[left] меньше, чем height[right], сдвигаем указатель left вправо (увеличиваем его).
	•	Если height[right] меньше или равен height[left], сдвигаем указатель right влево (уменьшаем его).
	5.	Повторяем шаги 2-4, пока указатели не встретятся.
	6.	Возвращаем максимальный найденный объём воды.
Решение:
```python
def maxArea(height):
    left, right = 0, len(height) - 1
    max_area = 0
    
    while left < right:
        # Вычисляем текущий объём воды
        area = min(height[left], height[right]) * (right - left)
        max_area = max(max_area, area)
        
        # Сдвигаем указатель, чтобы попытаться найти большее значение
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    
    return max_area
```
