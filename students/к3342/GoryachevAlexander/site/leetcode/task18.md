# 22. Generate Parentheses
1.	Мы начинаем с пустой строки и рекурсивно добавляем открывающую и закрывающую скобки.
2.	Открывающая скобка '(' может быть добавлена, если количество открытых скобок меньше n.
3.	Закрывающая скобка ')' может быть добавлена, если количество закрытых скобок меньше количества открытых, чтобы не нарушить баланс.
4.	Когда количество открытых и закрытых скобок достигает n, мы добавляем комбинацию в список результатов.

Решение:
```python
def generateParenthesis(n: int):
    result = []
    
    # Рекурсивная функция для формирования комбинаций
    def backtrack(current_string, open_count, close_count):
        # Если строка достигла длины 2*n, значит, мы нашли валидную комбинацию
        if len(current_string) == 2 * n:
            result.append(current_string)
            return
        
        # Добавляем открывающую скобку, если их меньше n
        if open_count < n:
            backtrack(current_string + '(', open_count + 1, close_count)
        
        # Добавляем закрывающую скобку, если их меньше чем открытых
        if close_count < open_count:
            backtrack(current_string + ')', open_count, close_count + 1)
    
    # Стартуем с пустой строки и счетчиков открытых и закрытых скобок
    backtrack('', 0, 0)
    
    return result
```
