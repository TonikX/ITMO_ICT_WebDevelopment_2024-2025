# 20. Valid Parentheses
1.	Проходим по каждому символу строки:
•	Если это открывающая скобка ('(', '{', '['), добавляем ее в стек.
•	Если это закрывающая скобка (')', '}', ']'):
•	Проверяем, не пуст ли стек. Если пуст, значит, это закрывающая скобка без соответствующей открывающей, и строка невалидна.
•	Если стек не пуст, берем верхний элемент стека и проверяем, соответствует ли он закрывающей скобке. Если не соответствует, строка невалидна.
•	Если соответствует, удаляем верхушку стека.
2.	После прохода по всей строке:
•	Если стек пуст, значит, все скобки были корректно закрыты, и строка валидна.
•	Если в стеке остались элементы, значит, есть незакрытые скобки, и строка невалидна.
Решение:
```python
def isValid(s: str) -> bool:
    stack = []
    # Сопоставление закрывающих скобок с открывающими
    matching_brackets = {')': '(', '}': '{', ']': '['}

    for char in s:
        if char in matching_brackets.values():  # Открывающая скобка
            stack.append(char)
        elif char in matching_brackets:  # Закрывающая скобка
            if not stack or stack[-1] != matching_brackets[char]:
                return False
            stack.pop()

    return not stack  # Если стек пуст, то строка валидна
```
