# 9. Palindrome Number
Алгоритм решения задачи:
	1.	Число, которое является палиндромом, читается одинаково с обеих сторон.
	2.	Для проверки палиндрома можно инвертировать число и сравнить его с оригиналом.
	3.	Важно учитывать, что числа с отрицательным знаком не могут быть палиндромами.
	4.	Если число равно инвертированному числу, то это палиндром.
Решение:
```python
def isPalindrome(x: int) -> bool:
    # Отрицательные числа не могут быть палиндромами
    if x < 0:
        return False
    
    # Сохраняем оригинальное число
    original = x
    reversed_num = 0
    
    # Инвертируем число
    while x > 0:
        reversed_num = reversed_num * 10 + x % 10
        x //= 10
    
    # Сравниваем исходное и инвертированное число
    return original == reversed_num
```
