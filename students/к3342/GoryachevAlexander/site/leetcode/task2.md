# Minimize Length of Array Using Operations
Для решения этой задачи ключевое замечание заключается в том, что операция вставки nums[i] % nums[j] в конец массива и удаления элементов i и j уменьшает массив. Так как результат операции nums[i] % nums[j] всегда меньше, чем nums[j], операция может генерировать меньшие значения.

Основная идея:
	1.	Если в какой-то момент все элементы массива будут кратны числу d, то все операции приведут к числу d. Это означает, что массив в конце концов сведется к одному числу d.
	2.	Минимальная длина массива будет равна числу различных делителей наибольшего общего делителя (НОД) всех чисел в массиве. Если НОД равен d, то после всех операций массив сведется к числам, кратным d.

Подход:
	1.	Найдем НОД всех элементов массива. Это поможет нам понять наименьшее число, которое может быть получено после всех операций.
	2.	Посчитаем количество различных кратных этому НОД, которые присутствуют в массиве.
	3.	Ответом будет количество таких различных кратных.

Шаги:
	1.	Вычислить НОД всех элементов массива.
	2.	Посчитать количество различных кратных НОД, присутствующих в массиве.
	3.	Ответом будет количество таких кратных.

Решение:
```python
import math
def minLength(nums):
    # Шаг 1: Вычисляем НОД всех элементов массива
    gcd_val = nums[0]
    for num in nums[1:]:
        gcd_val = math.gcd(gcd_val, num)

    # Шаг 2: Считаем количество различных кратных НОД в массиве
    multiples = set()
    for num in nums:
        if num % gcd_val == 0:
            multiples.add(num)
    
    # Ответ - количество различных кратных НОД
    return len(multiples)
```
