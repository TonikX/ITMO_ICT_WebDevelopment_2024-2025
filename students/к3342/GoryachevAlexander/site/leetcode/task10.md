# Integer to Roman
1.	Мы знаем, какие римские символы соответствуют определенным числовым значениям. Например:
	•	1000 → “M”
	•	900 → “CM”
	•	500 → “D”
	•	400 → “CD”
	•	100 → “C”
	•	90 → “XC”
	•	50 → “L”
	•	40 → “XL”
	•	10 → “X”
	•	9 → “IX”
	•	5 → “V”
	•	4 → “IV”
	•	1 → “I”
Пройдём по этим значениям начиная с наибольшего и будем вычитать их из числа, добавляя соответствующий римский символ к результату.
После вычитания продолжаем с оставшейся частью числа, пока не дойдем до нуля.
Решение:
```python
def intToRoman(num):
    # Список всех римских чисел в убывающем порядке
    roman_symbols = [
        (1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
        (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
        (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I")
    ]
    
    result = ""
    
    # Проходим по каждому числовому значению и его римскому эквиваленту
    for value, symbol in roman_symbols:
        while num >= value:
            result += symbol  # Добавляем символ к результату
            num -= value  # Уменьшаем число на соответствующую величину
    
    return result
```
