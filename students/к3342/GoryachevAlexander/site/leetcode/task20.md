# 26. Remove Duplicates from Sorted Array
1.	Инициализация двух указателей:
	•	Первый указатель i будет указывать на текущую уникальную позицию, куда нужно записать новый уникальный элемент.
	•	Второй указатель j будет перебирать все элементы массива от начала до конца.
2.	Итерация по массиву:
•	Для каждого элемента nums[j] проверяем, является ли он уникальным, сравнив его с предыдущим элементом nums[i-1].
•	Если элемент nums[j] не равен предыдущему, то это уникальный элемент, и мы записываем его на позицию i, после чего увеличиваем i.
3.	Результат:
•	После завершения итерации, i будет содержать количество уникальных элементов.
•	Массив будет изменен так, что первые i элементов содержат все уникальные значения.


Решение:
```python
# Определение структуры узла связанного списка
def removeDuplicates(nums):
    if not nums:
        return 0

    i = 1  # Указатель для позиции, куда будем записывать уникальные элементы

    for j in range(1, len(nums)):
        if nums[j] != nums[j - 1]:  # Если текущий элемент не равен предыдущему
            nums[i] = nums[j]  # Записываем уникальный элемент на позицию i
            i += 1  # Увеличиваем i

    return i  # Возвращаем количество уникальных элементов
```
