# 15. 3SUM
1.	Сначала отсортируем массив. Это упрощает задачу поиска троек, так как при сортировке мы можем эффективно избегать дублирования и использовать два указателя для нахождения нужных чисел.
2.	Пройдем по массиву с помощью одного указателя, фиксируя одно число, а для оставшейся части массива будем искать два числа, которые в сумме с этим числом дают 0.
3.	Для поиска этих двух чисел будем использовать два указателя — один с начала массива (после текущего фиксированного числа), а другой с конца массива. Мы будем двигать эти указатели в зависимости от того, насколько сумма текущих чисел меньше или больше нуля.
4.	Чтобы избежать дублирования, будем пропускать одинаковые элементы.

Решение:
```python
def threeSum(nums):
    nums.sort()  # Сортируем массив
    result = []
    
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:  # Пропускаем дубликаты
            continue
        
        left, right = i + 1, len(nums) - 1  # Инициализируем два указателя
        
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            
            if total < 0:
                left += 1  # Нужно увеличить сумму, двигаем левый указатель вправо
            elif total > 0:
                right -= 1  # Нужно уменьшить сумму, двигаем правый указатель влево
            else:
                result.append([nums[i], nums[left], nums[right]])  # Нашли тройку
                
                # Пропускаем дубликаты
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1
                
                # Двигаем указатели после нахождения пары
                left += 1
                right -= 1
    
    return result
```
