# 19. Remove Nth Node From End of List
1.	Два указателя: Используем два указателя, которые будут двигаться по списку. Один указатель будет идти на n шагов вперед, а второй начнется с головы списка.
2.	Перемещение указателей: После того как первый указатель пройдет n шагов, начинаем двигать оба указателя одновременно, пока первый не достигнет конца списка. В этот момент второй указатель будет указывать на узел, который нужно удалить (поскольку первый указатель был на n шагов впереди).
3.	Удаление узла: Когда второй указатель указывает на узел, который нужно удалить, просто изменяем указатель на предыдущий узел, чтобы исключить его из списка.
4.	Особые случаи: Если n равно длине списка, то нужно удалить первый узел (голову списка).
Решение:
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def removeNthFromEnd(head: ListNode, n: int) -> ListNode:
    # Создаем фиктивный узел для удобства работы с головой списка
    dummy = ListNode(0)
    dummy.next = head
    fast = slow = dummy
    
    # Перемещаем fast на n шагов вперед
    for _ in range(n + 1):
        fast = fast.next
    
    # Перемещаем оба указателя до тех пор, пока fast не достигнет конца
    while fast:
        fast = fast.next
        slow = slow.next
    
    # Удаляем n-й узел с конца
    slow.next = slow.next.next
    
    return dummy.next
```
