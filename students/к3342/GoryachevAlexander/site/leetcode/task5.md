# 7. Reverse Integer
1. Проверяем знак числа.
2.	Обрабатываем его как строку, переворачиваем цифры.
3.	Преобразуем строку обратно в число и проверяем, не выходит ли оно за пределы 32-битного диапазона.
Решение:
```python
def reverse(x: int) -> int:
    # Определяем границы 32-битного целого числа
    INT_MIN, INT_MAX = -2**31, 2**31 - 1
    
    # Обрабатываем знак числа
    sign = -1 if x < 0 else 1
    x *= sign
    
    # Переворачиваем число как строку
    reversed_x = int(str(x)[::-1])
    
    # Восстанавливаем знак и проверяем на выход за границы
    reversed_x *= sign
    
    if reversed_x < INT_MIN or reversed_x > INT_MAX:
        return 0
    
    return reversed_x
```
