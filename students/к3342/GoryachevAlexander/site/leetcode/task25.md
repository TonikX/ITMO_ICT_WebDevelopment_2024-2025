# 32. Longest Valid Parentheses
1.	Стек для индексов: Будем использовать стек для хранения индексов открывающихся скобок '(' и индекса предыдущей скобки, чтобы отслеживать длину действительных подстрок.
2.	Проход по строке:
•	Если текущий символ — '(', мы добавляем его индекс в стек.
•	Если текущий символ — ')', мы проверяем стек:
•	Если стек не пуст, извлекаем из него последний элемент (индекс открывающей скобки). Если элемент есть, значит мы нашли пару скобок, и длина действительной подстроки увеличивается.
•	Если стек пуст, значит текущая закрывающая скобка не имеет пары, и мы добавляем в стек текущий индекс.
3.	Максимальная длина: Для каждой найденной валидной подстроки вычисляем её длину, используя разницу между текущим индексом и индексом в стеке.
Решение:
```python
def longestValidParentheses(s: str) -> int:
    stack = [-1]  # Начальный элемент для удобства вычислений
    max_length = 0

    for i, char in enumerate(s):
        if char == '(':
            stack.append(i)  # Добавляем индекс открывающей скобки
        else:
            stack.pop()  # Убираем элемент, если нашли пару скобок
            if stack:
                max_length = max(max_length, i - stack[-1])  # Вычисляем длину
            else:
                stack.append(i)  # Если стек пуст, добавляем текущий индекс
    
    return max_length
```
