# 10. Regular Expression Matching
Алгоритм решения задачи:
	1.	Число, которое является палиндромом, читается одинаково с обеих сторон.
	2.	Для проверки палиндрома можно инвертировать число и сравнить его с оригиналом.
	3.	Важно учитывать, что числа с отрицательным знаком не могут быть палиндромами.
	4.	Если число равно инвертированному числу, то это палиндром.
Решение:
```python
def isMatch(s: str, p: str) -> bool:
    # dp[i][j] будет означать, что s[0..i-1] совпадает с p[0..j-1]
    dp = [[False] * (len(p) + 1) for _ in range(len(s) + 1)]
    dp[0][0] = True  # Пустая строка совпадает с пустым паттерном
    
    # Обработка паттернов, начинающихся с *
    for j in range(1, len(p) + 1):
        if p[j - 1] == '*':
            dp[0][j] = dp[0][j - 2]
    
    # Заполнение таблицы dp
    for i in range(1, len(s) + 1):
        for j in range(1, len(p) + 1):
            if p[j - 1] == s[i - 1] or p[j - 1] == '.':
                dp[i][j] = dp[i - 1][j - 1]
            elif p[j - 1] == '*':
                dp[i][j] = dp[i][j - 2] or (dp[i - 1][j] and (s[i - 1] == p[j - 2] or p[j - 2] == '.'))
    
    return dp[len(s)][len(p)]
```
