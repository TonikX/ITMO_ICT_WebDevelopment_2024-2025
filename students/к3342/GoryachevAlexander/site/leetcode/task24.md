# 31. Next Permutation
1.	Поиск самого правого элемента, который нарушает убывание:
•	Идем с конца массива и ищем первый элемент, который меньше следующего (то есть нарушает убывание). Этот элемент называется pivot.
2.	Поиск элемента, который можно поменять с pivot:
•	Теперь нужно найти минимальный элемент справа от pivot, который больше его, чтобы можно было сделать перестановку наименьшую, но больше текущей.
3.	Меняем эти два элемента:
•	Поменяем найденный элемент с pivot.
4.	Переворачиваем все элементы после pivot:
•	После того как мы поменяли два элемента, для получения наименьшей перестановки, все элементы справа от pivot нужно отсортировать в порядке возрастания (просто перевернуть их, так как они уже в убывающем порядке).
5.	Если такого элемента, который нарушает убывание, не найдено (т.е. весь массив отсортирован в убывающем порядке), то мы просто возвращаем минимальную перестановку — отсортированный массив.

Решение:
```python
def nextPermutation(nums):
    # Шаг 1: Найти индекс pivot (первый элемент, который нарушает убывание)
    n = len(nums)
    i = n - 2
    while i >= 0 and nums[i] >= nums[i + 1]:
        i -= 1
    
    # Если такой элемент найден
    if i >= 0:
        # Шаг 2: Найти элемент, который больше nums[i] и заменить
        j = n - 1
        while nums[j] <= nums[i]:
            j -= 1
        
        # Поменять nums[i] и nums[j]
        nums[i], nums[j] = nums[j], nums[i]
    
    # Шаг 3: Перевернуть элементы после индекса i
    left, right = i + 1, n - 1
    while left < right:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
        right -= 1
```
