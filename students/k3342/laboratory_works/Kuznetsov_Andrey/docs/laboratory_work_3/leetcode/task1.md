# [Remove Duplicates from Sorted Array II](https://leetcode.com/problems/remove-duplicates-from-sorted-array-ii/?envType=study-plan-v2&envId=top-interview-150)

## Решение

Для решения задачи используется метод двух указателей:

1. Инициализируем два указателя:
   - `j` для записи уникальных элементов с ограничением на два повторения.
   
2. Проходим по массиву начиная с третьего элемента (индекса 2) и проверяем:
   - Если текущий элемент не равен предыдущему элементу, записываем его на позицию `j` и увеличиваем `j`.
   - Если текущий элемент равен предыдущему, то проверяем, встречается ли этот элемент более двух раз подряд. Если нет, записываем его на позицию `j` и увеличиваем `j`.

3. Возвращаем количество уникальных элементов в начале массива.

### Код решения

```python
def removeDuplicates(nums):
    if len(nums) <= 2:
        return len(nums)
    
    # Указатель для записи уникальных элементов
    j = 1
    
    # Проходим по массиву с индекса 2
    for i in range(2, len(nums)):
        # Если текущий элемент не равен элементу на позиции j-1 (или вторая копия этого элемента), записываем его
        if nums[i] != nums[j-1]:
            j += 1
            nums[j] = nums[i]
    
    # Возвращаем количество уникальных элементов
    return j + 1
```
