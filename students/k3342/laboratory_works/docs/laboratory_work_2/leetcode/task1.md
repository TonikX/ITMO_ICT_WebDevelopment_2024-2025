# [Слияние двух отсортированных массивов](https://leetcode.com/problems/merge-sorted-array/submissions/1471338646/?envType=study-plan-v2&envId=top-interview-150)

## Решение

Для решения задачи используется метод двух указателей:

1. Инициализируем два указателя:
   - `p1` для последнего элемента в активной части `nums1` (индекс `m - 1`).
   - `p2` для последнего элемента в `nums2` (индекс `n - 1`).
2. Третий указатель `p` указывает на последнюю позицию в массиве `nums1` (индекс `m + n - 1`).
3. Сравниваем элементы, на которые указывают `p1` и `p2`, и вставляем больший элемент в позицию `p`.
4. Повторяем процесс, пока элементы одного из массивов не будут исчерпаны.
5. Если элементы остались в `nums2`, копируем их в начало `nums1`.

### Код решения

```python
def merge(nums1, m, nums2, n):
    # Инициализация указателей
    p1, p2 = m - 1, n - 1
    p = m + n - 1

    # Объединение массивов с конца
    while p1 >= 0 and p2 >= 0:
        if nums1[p1] > nums2[p2]:
            nums1[p] = nums1[p1]
            p1 -= 1
        else:
            nums1[p] = nums2[p2]
            p2 -= 1
        p -= 1

    # Копирование оставшихся элементов из nums2
    while p2 >= 0:
        nums1[p] = nums2[p2]
        p2 -= 1
        p -= 1
```
