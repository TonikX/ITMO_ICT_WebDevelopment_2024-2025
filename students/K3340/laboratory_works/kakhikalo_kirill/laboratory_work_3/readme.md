# УчебнаяСистема

## Описание проекта

Проект предназначен для автоматизации процессов в учебном отделе колледжа. Основные функции системы:

- **Преподаватели:** Хранение сведений о каждом преподавателе: ФИО, дисциплины, которые он преподает, и номер
  закрепленного за ним кабинета (кабинет может отсутствовать).
- **Студенты:** Хранение сведений о студентах: фамилия, имя, группа, а также оценка по каждой дисциплине в текущем
  семестре.
- **Оценки:** Замдекан может добавлять, изменять и удалять оценки студентов по дисциплинам.
- **Расписание:** Диспетчер учебной части формирует расписание занятий, где указывается время, аудитория, группа и
  преподаватель.

## Модель данных

Основные сущности и связи:

1. **Teacher (Преподаватель)**
    - *Поля:* `teacher_id`, `name`, `job_title`
    - *Описание:* Хранит данные о преподавателях. У преподавателя могут быть назначены дисциплины, а также (не всегда)
      закреплена аудитория.

2. **AcademicDiscipline (Дисциплина)**
    - *Поля:* `discipline_id`, `discipline_name`, `practice_duration`, `total_duration`, `attestation_type`
    - *Описание:* Содержит сведения о дисциплинах, которые преподаются в колледже.

3. **Classroom (Аудитория)**
    - *Поля:* `classroom_id`, `number`, `type`, `address`
    - *Описание:* Данные об аудиториях. Некоторые преподаватели могут не иметь закрепленной аудитории.

4. **Teacher-Dicipline Association (Преподаватель – Дисциплина)**
    - *Описание:* Модель, связывающая преподавателей и дисциплины через таблицу TeachingPermit (разрешение на
      преподавание).

5. **Group (Группа)**
    - *Поля:* `group_id`, `programm_code`, `maximum_students_amount`, `start_date`, `end_date`
    - *Описание:* Группы студентов, в которых учатся студенты колледжа.

6. **Student (Студент)**
    - *Поля:* `student_id`, `group_id`, `fio`, `contact`
    - *Описание:* Сведения о студентах (фамилия, имя, группа).

7. **Result (Оценка)**
    - *Поля:* `result_id`, `class_id`, `result`, `student_id`
    - *Описание:* Хранит оценки студентов по дисциплинам за семестр. Замдекан вносит и меняет оценки.

8. **ClassSession (Занятие / Расписание)**
    - *Поля:* `class_id`, `date`, `classes_order_number`, `type`, `group_id`, `classroom_id`, `teacher_id`,
      `discipline_id`
    - *Описание:* Содержит информацию о расписании занятий (какая группа, когда, где и какой преподаватель ведет занятие
      по определенной дисциплине).

## Функциональные возможности

- **Регистрация и аутентификация:** Система использует Djoser для регистрации, авторизации по токенам (с использованием
  TokenAuthentication) и получения информации о текущем пользователе.
- **CRUD операции:** Замдекан может добавлять, изменять и удалять данные о преподавателях, студентах и оценках.
- **Расписание:** Диспетчер учебной части имеет возможность формировать и редактировать расписание занятий.

## Технологии

- **Backend:** Django, Django REST Framework
- **Аутентификация:** Djoser
- **Документация API:** Swagger (drf-yasg)
- **База данных:** SQLite
