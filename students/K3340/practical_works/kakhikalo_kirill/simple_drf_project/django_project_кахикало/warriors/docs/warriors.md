# Эндпоинты: Warriors

В этом разделе описаны эндпоинты для работы с воинами: получение списка, 
создание, получение деталей, редактирование и удаление воина.

## 1. Получение списка воинов

**URL:** `/warriors/`

**Метод:** `GET`

**Описание:**  
Эндпоинт возвращает полный список воинов, включая их данные, 
связанные профессии и навыки (через промежуточную модель).  
Используется представление `WarriorListAPIView`.
