# Проект Warriors

Проект представляет собой REST API
для управления воинами, их профессиями и навыками. В основе проекта лежит работа с моделями, сериализаторами и
эндпоинтами, которые позволяют выполнять CRUD операции над данными.

## Основные составляющие проекта

- **Модели:**
    - **Warrior** – модель, описывающая воина (имя, уровень, раса).
    - **Profession** – модель, описывающая профессию воина (название, описание).
    - **Skill** – модель, описывающая навыки.
    - **SkillOfWarrior** – промежуточная модель для хранения информации об уровне освоения навыка воином.

- **API:**
    - Вывод полного списка воинов с их профессиями и навыками.
    - Получение детальной информации о конкретном воине.
    - Создание, редактирование и удаление воинов.
