# Эндпоинты: Profession

В этом разделе описаны эндпоинты, 
предназначенные для создания записей о профессиях, 
которые могут быть назначены воинам.

## 1. Создание профессии

**URL:** `/profession/create/`

**Метод:** `POST`

**Описание:**  
Эндпоинт позволяет создать новую профессию. 
При отправке запроса с данными профессии (название, описание) 
система сохраняет запись в базе данных.

**Пример:**

```
POST /profession/create/
Content-Type: application/json

{
  "title": "Маг",
  "description": "Описание мага"
}
```
