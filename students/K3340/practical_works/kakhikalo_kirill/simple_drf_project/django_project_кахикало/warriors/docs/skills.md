# Эндпоинты: Skills

В данном разделе описаны эндпоинты для работы с навыками. 
Здесь можно как просматривать существующие навыки, так и создавать новые.

## 1. Получение списка навыков

**URL:** `/skills/`

**Метод:** `GET`

**Описание:**  
Эндпоинт возвращает список всех навыков, доступных в системе. 
Данные выводятся в виде массива объектов, содержащих информацию 
о каждом навыке.

## 2. Создание навыка

**URL:** `/skills/create/`

**Метод:** `POST`

Описание:
Эндпоинт позволяет создать новый навык. 
Для этого в теле запроса необходимо передать необходимые данные 
(например, название навыка).
