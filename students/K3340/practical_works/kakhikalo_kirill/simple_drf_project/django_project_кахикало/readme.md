# Проект "Воины и их навыки"

## Описание проекта

Проект состоит из двух основных частей:

1. **Модели и база данных**  
   - **Warrior** — модель воина, содержит имя, уровень, расу, а также связь с профессией и навыками.
   - **Profession** — модель профессии, содержит название и описание.
   - **Skill** — модель навыка, содержит название навыка.
   - **SkillOfWarrior** — промежуточная модель, которая связывает воина и навык, а также хранит уровень освоения навыка.

2. **API**  
   Реализованы следующие эндпоинты:
   - **Получение списка всех воинов** с полной информацией (профессия, навыки).
   - **Получение, редактирование и удаление информации о конкретном воине** по его id.
   - Дополнительные эндпоинты для работы с навыками:
     - Получение списка всех навыков.
     - Создание нового навыка.
     - Добавление (присвоение) навыка воину.

## Используемые технологии

- Python 3.x
- Django 3.x или 4.x
- Django REST Framework
- SQLite
